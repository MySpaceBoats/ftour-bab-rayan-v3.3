# Salons Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ajouter un onglet « Salons » au Hub : tout membre crée un salon thématique avec son feed de messages et sa visio de groupe Jitsi.

**Architecture:** Copie du module Meetup. Deux tables D1 (`sl_salons`, `sl_posts`), une couche de données pure testable (`worker/salon-d1.ts`), des routes REST `/hub/salon/*` (`worker/salon.ts`) branchées dans `worker/hub.ts`, et un module client `client/src/features/hub/salon/` (liste, page de salon avec feed en polling, panneau Jitsi en iframe chargé au clic).

**Tech Stack:** TypeScript 5.9, zod, Cloudflare D1 (fake SQLite `node:sqlite` en test), vitest, React 19, wouter, Tailwind, lucide-react, sonner. Aucune nouvelle dépendance.

**Spec:** `docs/superpowers/specs/2026-10-18-salons-design.md`

## Global Constraints

- Salons ouverts à tous les membres du Hub (`HOST_OK` de `worker/stay-d1.ts` : membre actif ET bénévole confirmé/présent). Pas de salon privé.
- Limites : 5 salons/jour/membre, 20 messages/minute/membre, titre ≤80, sujet ≤500, message ≤2000, page de messages = 30.
- Statuts de salon : `active`, `archived`, `hidden`. `archived` = lecture seule ; `hidden` = introuvable (404).
- `room` (jeton aléatoire ≥16 car.) n'apparaît **que** dans `GET salon/salons/:id`, jamais dans la liste ni dans l'admin.
- Messages : soft delete (`deleted_at`) par l'auteur uniquement. Texte rendu comme texte, jamais comme HTML.
- Visio : iframe `https://<VITE_JITSI_DOMAIN || meet.jit.si>/babrayan-<room>`, chargée seulement au clic.
- Erreurs : `HubError` (`invalid`, `not_found`, `forbidden`, `rate_limited`, `conflict`) comme Meetup. Messages en français.
- Style : 2 espaces, guillemets doubles, code court, commentaires `// ponytail:` pour les raccourcis assumés.
- Pas de nouveau secret ni binding Cloudflare. **Aucune exécution de `salon.sql` sur la base de prod ni aucun déploiement sans ordre explicite de Reda.**
- Branche dédiée depuis `origin/main` (la branche courante `feat/friends-follow` contient des modifications non commitées d'autres travaux : ne pas les committer).

## Review Focus

1. Message fait d'espaces/retours à la ligne seulement, ou de 2001 caractères → refusé (`invalid`), jamais inséré. *(Task 2)*
2. Message contenant du HTML (`<img onerror=…>`) → stocké et renvoyé tel quel en texte brut, jamais interprété. *(Task 2 test, Task 5 rendu `{post.body}`)*
3. Identifiant d'URL non numérique (`/salons/abc`) ou curseur falsifié → 400 `invalid`, pas 500. *(Task 3)*
4. Créateur suspendu ou non confirmé → ses salons disparaissent de la liste et du détail. *(Task 1)*
5. Salon vide (0 message) et salon archivé : la page doit rester utilisable (état vide, composeur remplacé par un avis « archivé »). *(Task 1 + Task 5)*

```sql
-- Salons thématiques du Hub (feed + visio Jitsi). Idempotent. Prérequis : worker/d1/hub.sql.
-- Appliquer : wrangler d1 execute ftour-bab-rayan-prod-db --remote --file worker/d1/salon.sql
-- (staging : --env staging, base ftour-bab-rayan-staging-db)
CREATE TABLE IF NOT EXISTS sl_salons (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  member_id INTEGER NOT NULL REFERENCES hub_members(id) ON DELETE CASCADE,
  title TEXT NOT NULL CHECK (length(title) BETWEEN 1 AND 80),
  topic TEXT NOT NULL CHECK (length(topic) BETWEEN 1 AND 500),
  -- jeton aléatoire du nom de salle Jitsi : ne sort que par le détail d'un salon
  room TEXT NOT NULL UNIQUE CHECK (length(room) >= 16),
  status TEXT NOT NULL DEFAULT 'active' CHECK (status IN ('active','archived','hidden')),
  last_post_at TEXT,
  created_at TEXT NOT NULL DEFAULT (strftime('%Y-%m-%dT%H:%M:%fZ','now'))
);
CREATE INDEX IF NOT EXISTS idx_sl_salons_status ON sl_salons(status, last_post_at DESC);
CREATE INDEX IF NOT EXISTS idx_sl_salons_member ON sl_salons(member_id, created_at);

CREATE TABLE IF NOT EXISTS sl_posts (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  salon_id INTEGER NOT NULL REFERENCES sl_salons(id) ON DELETE CASCADE,
  member_id INTEGER NOT NULL REFERENCES hub_members(id) ON DELETE CASCADE,
  body TEXT NOT NULL CHECK (length(body) BETWEEN 1 AND 2000),
  deleted_at TEXT,
  created_at TEXT NOT NULL DEFAULT (strftime('%Y-%m-%dT%H:%M:%fZ','now'))
);
CREATE INDEX IF NOT EXISTS idx_sl_posts_salon ON sl_posts(salon_id, id DESC);
CREATE INDEX IF NOT EXISTS idx_sl_posts_member ON sl_posts(member_id, created_at);
```

```ts
/**
 * Salons thématiques du Hub (feed + visio Jitsi) — couche données sur Cloudflare D1 (tables sl_*). Réutilise les membres du Hub.
 * Aucun import HTTP / Supabase : testable avec un faux D1. Le temps est toujours passé en paramètre (nowMs).
 */
import { z } from "zod";
import type { D1Like } from "./gallery-d1";
import { HubError, iso, HOUR_MS, type MemberRow } from "./hub-d1";
import { HOST_OK } from "./stay-d1";

export const SL_LIMITS = { salonsPerDay: 5, postsPerMinute: 20, title: 80, topic: 500, body: 2000, pageSize: 30 };
const DAY_MS = 24 * HOUR_MS;
const MINUTE_MS = 60_000;
// ponytail: curseur = "<activité ISO>_<id>" ; un format invalide est refusé, pas deviné
const CURSOR_RE = /^([0-9TZ:.-]{20,30})_(\d+)$/;

export type SalonStatus = "active" | "archived" | "hidden";
export interface SalonPerson { id: number; display_name: string; avatar_key: string | null }
export interface SalonCard {
  id: number; title: string; topic: string; status: SalonStatus; post_count: number;
  last_post_at: string | null; created_at: string; mine: boolean; creator: SalonPerson;
}
export interface SalonDetail extends SalonCard { room: string }
export interface AdminSalon { id: number; title: string; status: SalonStatus; creator: string; post_count: number }

// ---- validation -----------------------------------------------------------

const text = (label: string, max: number) =>
  z.string({ required_error: `${label} requis`, invalid_type_error: `${label} invalide` })
    .transform(v => v.trim())
    .pipe(z.string().min(1, `${label} requis`).max(max, `${label} trop long (${max} caractères max)`));

const salonSchema = z.object({ title: text("Titre", SL_LIMITS.title), topic: text("Sujet", SL_LIMITS.topic) });

export function parse<S extends z.ZodTypeAny>(schema: S, raw: unknown): z.infer<S> {
  const r = schema.safeParse(raw);
  if (!r.success) throw new HubError("invalid", r.error.issues[0]?.message ?? "Données invalides");
  return r.data;
}

// ---- create / list / detail ----------------------------------------------

export async function createSalon(d: D1Like, member: MemberRow, raw: unknown, nowMs: number): Promise<{ id: number }> {
  const c = parse(salonSchema, raw);
  const n = await d.prepare("SELECT COUNT(*) AS n FROM sl_salons WHERE member_id = ? AND created_at > ?").bind(member.id, iso(nowMs - DAY_MS)).first<{ n: number }>();
  if ((n?.n ?? 0) >= SL_LIMITS.salonsPerDay) throw new HubError("rate_limited", `Limite de ${SL_LIMITS.salonsPerDay} salons par jour atteinte`);
  const room = crypto.randomUUID().replaceAll("-", "");
  const row = await d.prepare("INSERT INTO sl_salons (member_id, title, topic, room, created_at) VALUES (?,?,?,?,?) RETURNING id")
    .bind(member.id, c.title, c.topic, room, iso(nowMs)).first<{ id: number }>();
  return { id: row!.id };
}

/** Alias: s = sl_salons, m = créateur (hub_members, comme HOST_OK l'attend). `extra` = colonnes en plus (ex. ", s.room"). */
const cardSelect = (extra = "") => `SELECT s.id, s.title, s.topic, s.status, s.last_post_at, s.created_at, s.member_id${extra},
    COALESCE(s.last_post_at, s.created_at) AS activity,
    (SELECT COUNT(*) FROM sl_posts p WHERE p.salon_id = s.id AND p.deleted_at IS NULL) AS post_count,
    m.id AS cr_id, m.display_name AS cr_name, m.avatar_key AS cr_avatar
  FROM sl_salons s JOIN hub_members m ON m.id = s.member_id`;

function toCard(r: any, viewerId: number): SalonCard {
  return {
    id: r.id, title: r.title, topic: r.topic, status: r.status, post_count: r.post_count ?? 0,
    last_post_at: r.last_post_at ?? null, created_at: r.created_at, mine: r.member_id === viewerId,
    creator: { id: r.cr_id, display_name: r.cr_name, avatar_key: r.cr_avatar },
  };
}

/** Salons actifs, activité la plus récente d'abord, pagination keyset sur (activité, id). */
export async function listSalons(d: D1Like, viewerId: number, o: { cursor?: string | null; limit?: number } = {}): Promise<{ salons: SalonCard[]; nextCursor: string | null }> {
  const lim = Math.min(Math.max(Math.trunc(o.limit ?? SL_LIMITS.pageSize) || SL_LIMITS.pageSize, 1), 50);
  const where = [HOST_OK, "s.status = 'active'"];
  const args: unknown[] = [];
  if (o.cursor) {
    const c = CURSOR_RE.exec(o.cursor);
    if (!c) throw new HubError("invalid", "Curseur invalide");
    where.push("(COALESCE(s.last_post_at, s.created_at) < ? OR (COALESCE(s.last_post_at, s.created_at) = ? AND s.id < ?))");
    args.push(c[1], c[1], Number(c[2]));
  }
  const { results } = await d.prepare(`${cardSelect()} WHERE ${where.join(" AND ")} ORDER BY activity DESC, s.id DESC LIMIT ?`)
    .bind(...args, lim + 1).all<any>();
  const page = results.slice(0, lim);
  const last = page[page.length - 1];
  return { salons: page.map(r => toCard(r, viewerId)), nextCursor: results.length > lim && last ? `${last.activity}_${last.id}` : null };
}

/** Détail (avec `room`) d'un salon actif ou archivé ; masqué, inconnu ou créateur suspendu = 404. */
export async function getSalon(d: D1Like, viewerId: number, id: number): Promise<SalonDetail> {
  const r = await d.prepare(`${cardSelect(", s.room")} WHERE s.id = ? AND s.status IN ('active','archived') AND ${HOST_OK}`).bind(id).first<any>();
  if (!r) throw new HubError("not_found", "Salon introuvable");
  return { ...toCard(r, viewerId), room: r.room };
}

// ---- archive / admin ------------------------------------------------------

export async function archiveSalon(d: D1Like, member: MemberRow, id: number): Promise<void> {
  const s = await d.prepare("SELECT member_id, status FROM sl_salons WHERE id = ?").bind(id).first<{ member_id: number; status: SalonStatus }>();
  if (!s || s.status === "hidden") throw new HubError("not_found", "Salon introuvable");
  if (s.member_id !== member.id) throw new HubError("forbidden", "Seul le créateur peut archiver ce salon");
  await d.prepare("UPDATE sl_salons SET status = 'archived' WHERE id = ? AND status = 'active'").bind(id).run();
}

export async function adminListSalons(d: D1Like): Promise<AdminSalon[]> {
  const { results } = await d.prepare(
    `SELECT s.id, s.title, s.status, m.display_name AS creator,
       (SELECT COUNT(*) FROM sl_posts p WHERE p.salon_id = s.id AND p.deleted_at IS NULL) AS post_count
     FROM sl_salons s JOIN hub_members m ON m.id = s.member_id ORDER BY s.id DESC LIMIT 100`,
  ).all<AdminSalon>();
  return results;
}

async function assertExists(d: D1Like, id: number): Promise<void> {
  if (!(await d.prepare("SELECT 1 AS ok FROM sl_salons WHERE id = ?").bind(id).first())) throw new HubError("not_found", "Salon introuvable");
}

/** Soft delete : le salon disparaît partout. */
export async function hideSalon(d: D1Like, id: number): Promise<void> {
  await assertExists(d, id);
  await d.prepare("UPDATE sl_salons SET status = 'hidden' WHERE id = ?").bind(id).run();
}

/** Suppression définitive : messages d'abord, pour ne pas dépendre du pragma de clés étrangères. */
export async function deleteSalon(d: D1Like, id: number): Promise<void> {
  await assertExists(d, id);
  await d.batch([
    d.prepare("DELETE FROM sl_posts WHERE salon_id = ?").bind(id),
    d.prepare("DELETE FROM sl_salons WHERE id = ?").bind(id),
  ]);
}
```

```ts
// ---- posts ----------------------------------------------------------------

export interface SalonPost { id: number; body: string; created_at: string; mine: boolean; author: SalonPerson }

const postSchema = z.object({ body: text("Message", SL_LIMITS.body) });

/** Statut d'un salon lisible (actif ou archivé, créateur valide) ; sinon 404. */
async function readableStatus(d: D1Like, salonId: number): Promise<SalonStatus> {
  const r = await d.prepare(
    `SELECT s.status FROM sl_salons s JOIN hub_members m ON m.id = s.member_id
     WHERE s.id = ? AND s.status IN ('active','archived') AND ${HOST_OK}`,
  ).bind(salonId).first<{ status: SalonStatus }>();
  if (!r) throw new HubError("not_found", "Salon introuvable");
  return r.status;
}

export async function createPost(d: D1Like, member: MemberRow, salonId: number, raw: unknown, nowMs: number): Promise<{ id: number }> {
  const c = parse(postSchema, raw);
  if ((await readableStatus(d, salonId)) !== "active") throw new HubError("conflict", "Ce salon est archivé");
  const n = await d.prepare("SELECT COUNT(*) AS n FROM sl_posts WHERE member_id = ? AND created_at > ?").bind(member.id, iso(nowMs - MINUTE_MS)).first<{ n: number }>();
  if ((n?.n ?? 0) >= SL_LIMITS.postsPerMinute) throw new HubError("rate_limited", `Limite de ${SL_LIMITS.postsPerMinute} messages par minute atteinte`);
  const row = await d.prepare("INSERT INTO sl_posts (salon_id, member_id, body, created_at) VALUES (?,?,?,?) RETURNING id")
    .bind(salonId, member.id, c.body, iso(nowMs)).first<{ id: number }>();
  // ponytail: deux requêtes, pas de transaction ; au pire last_post_at retarde d'un message
  await d.prepare("UPDATE sl_salons SET last_post_at = ? WHERE id = ?").bind(iso(nowMs), salonId).run();
  return { id: row!.id };
}

/** Messages non supprimés, plus récents d'abord ; curseur = id du dernier message renvoyé. */
export async function listPosts(d: D1Like, viewerId: number, salonId: number, o: { cursor?: string | null; limit?: number } = {}): Promise<{ posts: SalonPost[]; nextCursor: string | null }> {
  await readableStatus(d, salonId);
  const lim = Math.min(Math.max(Math.trunc(o.limit ?? SL_LIMITS.pageSize) || SL_LIMITS.pageSize, 1), 50);
  if (o.cursor && !/^\d{1,15}$/.test(o.cursor)) throw new HubError("invalid", "Curseur invalide");
  const { results } = await d.prepare(
    `SELECT p.id, p.body, p.created_at, p.member_id, m.id AS au_id, m.display_name AS au_name, m.avatar_key AS au_avatar
     FROM sl_posts p JOIN hub_members m ON m.id = p.member_id
     WHERE p.salon_id = ? AND p.deleted_at IS NULL AND ${HOST_OK}${o.cursor ? " AND p.id < ?" : ""}
     ORDER BY p.id DESC LIMIT ?`,
  ).bind(salonId, ...(o.cursor ? [Number(o.cursor)] : []), lim + 1).all<any>();
  const page = results.slice(0, lim);
  const last = page[page.length - 1];
  return {
    posts: page.map(r => ({
      id: r.id, body: r.body, created_at: r.created_at, mine: r.member_id === viewerId,
      author: { id: r.au_id, display_name: r.au_name, avatar_key: r.au_avatar },
    })),
    nextCursor: results.length > lim && last ? String(last.id) : null,
  };
}

export async function deletePost(d: D1Like, member: MemberRow, salonId: number, postId: number): Promise<void> {
  const p = await d.prepare("SELECT member_id, deleted_at FROM sl_posts WHERE id = ? AND salon_id = ?").bind(postId, salonId).first<{ member_id: number; deleted_at: string | null }>();
  if (!p || p.deleted_at) throw new HubError("not_found", "Message introuvable");
  if (p.member_id !== member.id) throw new HubError("forbidden", "Seul l'auteur peut supprimer son message");
  await d.prepare("UPDATE sl_posts SET deleted_at = ? WHERE id = ?").bind(iso(Date.now()), postId).run();
}
```

```ts
/** REST routes of the salons module, called from handleHubRequest for any /hub/salon/* path. */
import type { D1Like } from "./gallery-d1";
import * as H from "./hub-d1";
import * as S from "./salon-d1";
import { id, readJson } from "./hub-http";

export interface SalonCtx {
  d: D1Like;
  request: Request;
  url: URL;
  path: string; // after "salon/"
  now: () => number;
  json: (data: unknown, status?: number) => Response;
  member: () => Promise<H.MemberRow>;
  admin: () => Promise<void>;
  sign: (p: string | null) => Promise<string | null>;
}

/** avatar_key never leaves: only the signed URL does. */
const person = async (p: S.SalonPerson, sign: SalonCtx["sign"]) => ({ id: p.id, display_name: p.display_name, avatar: await sign(p.avatar_key) });
const presentCard = async <T extends S.SalonCard>(c: T, sign: SalonCtx["sign"]) => ({ ...c, creator: await person(c.creator, sign) });

export async function handleSalonRoute(c: SalonCtx): Promise<Response | null> {
  const { d, request, url, path, now, json, member, admin, sign } = c;
  const match = (method: string, re: RegExp) => (request.method === method ? re.exec(path) : null);
  const q = (k: string) => url.searchParams.get(k) ?? undefined;
  let m: RegExpExecArray | null;

  // ---- salons ------------------------------------------------------------
  if (match("GET", /^salons$/)) {
    const me = await member();
    const r = await S.listSalons(d, me.id, { cursor: q("cursor") });
    return json({ salons: await Promise.all(r.salons.map(x => presentCard(x, sign))), nextCursor: r.nextCursor });
  }
  if (match("POST", /^salons$/)) {
    const me = await member();
    return json(await S.createSalon(d, me, await readJson(request), now()));
  }
  if ((m = match("GET", /^salons\/([^/]+)$/))) {
    const me = await member();
    return json({ salon: await presentCard(await S.getSalon(d, me.id, id(m[1])), sign) });
  }
  if ((m = match("POST", /^salons\/([^/]+)\/archive$/))) {
    const me = await member();
    await S.archiveSalon(d, me, id(m[1]));
    return json({ ok: true });
  }

  // ---- posts -------------------------------------------------------------
  if ((m = match("GET", /^salons\/([^/]+)\/posts$/))) {
    const me = await member();
    const r = await S.listPosts(d, me.id, id(m[1]), { cursor: q("cursor") });
    return json({ posts: await Promise.all(r.posts.map(async p => ({ ...p, author: await person(p.author, sign) }))), nextCursor: r.nextCursor });
  }
  if ((m = match("POST", /^salons\/([^/]+)\/posts$/))) {
    const me = await member();
    return json(await S.createPost(d, me, id(m[1]), await readJson(request), now()));
  }
  if ((m = match("DELETE", /^salons\/([^/]+)\/posts\/([^/]+)$/))) {
    const me = await member();
    await S.deletePost(d, me, id(m[1]), id(m[2]));
    return json({ ok: true });
  }

  // ---- admin (Supabase bearer + role) ------------------------------------
  if (match("GET", /^admin\/salons$/)) { await admin(); return json({ salons: await S.adminListSalons(d) }); }
  if (match("POST", /^admin\/hide$/)) {
    await admin();
    await S.hideSalon(d, id((await readJson(request)).id));
    return json({ ok: true });
  }
  if (match("POST", /^admin\/delete$/)) {
    await admin();
    await S.deleteSalon(d, id((await readJson(request)).id));
    return json({ ok: true });
  }

  return null;
}
```

```ts
import { call } from "../api";

export interface SalonPerson { id: number; display_name: string; avatar: string | null }
export type SalonStatus = "active" | "archived" | "hidden";
export interface SalonCard {
  id: number; title: string; topic: string; status: SalonStatus; post_count: number;
  last_post_at: string | null; created_at: string; mine: boolean; creator: SalonPerson;
}
export interface SalonDetail extends SalonCard { room: string }
export interface SalonPost { id: number; body: string; created_at: string; mine: boolean; author: SalonPerson }

const qs = (cursor?: string | null) => (cursor ? `?cursor=${encodeURIComponent(cursor)}` : "");

export const listSalons = (cursor?: string | null) => call<{ salons: SalonCard[]; nextCursor: string | null }>("GET", `salon/salons${qs(cursor)}`);
export const getSalon = (id: number) => call<{ salon: SalonDetail }>("GET", `salon/salons/${id}`).then(r => r.salon);
export const createSalon = (form: { title: string; topic: string }) => call<{ id: number }>("POST", "salon/salons", { body: form });
export const archiveSalon = (id: number) => call<{ ok: true }>("POST", `salon/salons/${id}/archive`);
export const listPosts = (salonId: number, cursor?: string | null) => call<{ posts: SalonPost[]; nextCursor: string | null }>("GET", `salon/salons/${salonId}/posts${qs(cursor)}`);
export const createPost = (salonId: number, body: string) => call<{ id: number }>("POST", `salon/salons/${salonId}/posts`, { body: { body } });
export const deletePost = (salonId: number, postId: number) => call<{ ok: true }>("DELETE", `salon/salons/${salonId}/posts/${postId}`);
```

```tsx
  const { lang } = useI18n();
  const me = useHubMember();
  const [, params] = useRoute("/:lang/benevole/espace/salons/:id");
  const salonId = Number(params?.id);

  const [next, setNext] = useState<string | null>(null);

      if (e instanceof HubApiError && e.status === 404) { setSalon(null); return; }

    });
  }, [salonId]);

  // First page replaces the list; the poll merges new messages in front without losing older pages already loaded.
  const refresh = useCallback(async () => {
    try {
      const r = await sl.listPosts(salonId);
      setPosts(prev => {
        const known = new Set(r.posts.map(p => p.id));
        const oldest = r.posts[r.posts.length - 1]?.id ?? 0;
        return [...r.posts, ...prev.filter(p => p.id < oldest && !known.has(p.id))];
      });
      setNext(n => (n === null && r.nextCursor === null ? null : n ?? r.nextCursor));
    } catch { /* ponytail: un échec de polling est silencieux, le prochain tick réessaie */ }
  }, [salonId]);

  useEffect(() => {
    if (!me || !Number.isSafeInteger(salonId)) return;
    void loadSalon();
    void sl.listPosts(salonId).then(r => { setPosts(r.posts); setNext(r.nextCursor); }).catch(() => undefined);
  }, [me, salonId, loadSalon]);

  useEffect(() => {
    if (!me || !salon) return;
    const t = setInterval(() => { if (!document.hidden) void refresh(); }, POLL_MS);
    return () => clearInterval(t);
  }, [me, salon, refresh]);

  async function send(e: React.FormEvent) {
    e.preventDefault();
    const text = body.trim();
    if (!text || sending) return;
    setSending(true);
    try {
      await sl.createPost(salonId, text);
      setBody("");
      await refresh();
      logRef.current?.scrollTo({ top: 0 });
    } catch (err) {
      toast.error((err as Error).message);
    } finally {
      setSending(false);
    }
  }

    if (!next || loadingMore) return;
    setLoadingMore(true);
    try {
      const r = await sl.listPosts(salonId, next);
      setPosts(prev => [...prev, ...r.posts]);
      setNext(r.nextCursor);
    } catch (err) {
      toast.error((err as Error).message);
    } finally {
      setLoadingMore(false);
    }
  }

      await sl.deletePost(salonId, p.id);

    }
  }

  async function archive() {
    try {
      await sl.archiveSalon(salonId);
      toast.success("Salon archivé");
      await loadSalon();
    } catch (err) {
      toast.error((err as Error).message);
    }

  return (
    <HubShell me={me}>
      <div className="space-y-4">
        <Link href={back} className="inline-flex items-center gap-1 text-sm text-blue-800 hover:underline"><ArrowLeft size={14} aria-hidden /> Tous les salons</Link>

              <p className="flex items-center gap-2 text-xs text-slate-500">
```
