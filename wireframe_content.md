## Slide 7 : Page Programme - Calendrier
**Titre** : Programme - Calendrier Ramadan interactif

**Structure** :

## Slide 18 : Flux utilisateur - Bénévole
**Titre** : Parcours utilisateur - Devenir bénévole

**Étapes** :
1. Visite page d'accueil
2. Clic sur "Devenir bénévole"
3. Consultation du calendrier
4. Sélection du/des jour(s)
5. Remplissage du formulaire
6. Réception QR code
7. Présentation QR code le jour J
8. Validation par scan

---

## Slide 19 : Flux utilisateur - Donateur
**Titre** : Parcours utilisateur - Faire un don

**Étapes** :
1. Visite page d'accueil
2. Clic sur "Faire un don"
3. Choix du montant
4. Sélection mode de paiement
5. Remplissage formulaire
6. Confirmation promesse
7. Réception instructions (si virement)
8. Paiement

---

## Slide 20 : Récapitulatif technique
**Titre** : Stack technique et fonctionnalités

**Technologies** :
- React 19 + TypeScript
- Tailwind CSS 4
- tRPC pour l'API
- Base de données MySQL
- Authentification OAuth

**Fonctionnalités clés** :
- Génération QR codes
- Scan mobile
- Gestion multi-rôles
- Exports CSV
- Emails automatiques (à configurer)
